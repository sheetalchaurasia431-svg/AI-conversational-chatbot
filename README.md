🤖 AI Conversational Chatbot

An AI-powered conversational chatbot built using Python, LangChain, and Hugging Face. The chatbot provides an interactive interface for users to communicate with an AI model and maintain conversational context.

 🚀 Features

- 💬 Conversational interaction with an AI model
- 🧠 Maintains chat history
- 🔗 LangChain integration
- 🤗 Hugging Face model integration
- 🌐 Web-based frontend
- 🔐 API credentials managed using environment variables
- 🐍 Built with Python

 🛠️ Technologies Used

- Python
- LangChain
- Hugging Face
- HTML
- CSS
- JavaScript
- REST API
- Git & GitHub
